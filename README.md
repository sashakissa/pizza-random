# Яку піцу ми сьогодні їмо?

Фановий сайт: колесо обирає піцу, рахує, скільки брати на компанію, і вирішує, хто платить.

## Що вміє

- Колесо з піцами: можна прибрати зайве («Без м'яса», «Без морепродуктів») або додати свою піцу з ціною
- Скільки брати: кількість людей × апетит (2/3/4 шматки), піца 30 см = 8 шматків
- Два режими: усі піци однакові або різні (крутимо на кожну)
- «Хто платить»: скинутись порівну або рулетка по іменах
- Кнопка «Поділитися» (Web Share API, на десктопі копіює текст у буфер)
- Налаштування й імена зберігаються в браузері (localStorage)

## Структура

```
index.html   — увесь сайт: HTML, CSS і JS в одному файлі
og.png       — превʼю для соцмереж (1200×630)
```

Збирати нічого не треба, бекенду немає.

## Локально

Відкрий `index.html` у браузері або запусти:

```
npx serve .
```

## Деплой (Vercel)

1. vercel.com → Add New → Project → вибрати цей репозиторій
2. Framework Preset: **Other**, Build Command порожній, Output Directory `.`
3. Deploy

Кожен пуш у `main` деплоїться автоматично.

## Після деплою

- **Превʼю:** у `index.html` заміни `content="/og.png"` на повну адресу, наприклад `https://<домен>/og.png`. Telegram і Facebook відносний шлях не підхоплюють.
- **Статистика:** у коді є функція `track()`, вона шле події `spin`, `payer_roll`, `split`, `share`. Працює з Umami, Plausible або Vercel Analytics: досить додати їхній скрипт у `<head>`.

## Що змінювати

- Список піц і ціни: масив `DEF` на початку скрипта
- Жарти: масиви `LBL` (вердикт піци) і `PAY` (хто платить)
- Ціни приблизні, за 30 см
